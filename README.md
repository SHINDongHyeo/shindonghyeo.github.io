# 신동혁의 개발 일기

> 개발하면서 배우고, 부딪히고, 해결한 것들을 꾸준히 기록합니다.

🔗 **https://shindonghyeo.github.io**

## 이 블로그는

개발하면서 겪은 일을 일기처럼 남기는 공간입니다.
잘 정리된 글보다 그날 배운 것, 고민한 것, 해결한 문제를 솔직하게 기록하는 것을 목표로 합니다.

## 다시 시작하며

예전에도 블로그를 여러 개 운영했지만 주제가 너무 잡다했고, 무엇보다 글을 직접 쓰는 일이 힘들어서 중간에 관리를 멈추게 되었습니다. 그렇게 대부분의 블로그가 방치되었습니다.
그래서 이전 블로그들을 모두 정리하고, 이번에는 세 가지 원칙으로 다시 시작합니다.

- **개발 이야기만** 씁니다.
- **완벽하지 않아도 꾸준히** 씁니다.
- **AI의 도움을 적극적으로** 받습니다. 직접 쓰기 어렵다는 이유로 기록을 멈추기보다, AI의 힘을 빌려서라도 일단 글을 남기는 것에 의의를 둡니다.

## 어떤 글을 쓰나요

- 공부하면서 새로 알게 된 개념과 기술
- 개발하다 마주친 문제와 해결 과정
- 진행 중인 프로젝트의 기록과 회고

## 만든 방법

- [Astro](https://astro.build)로 만든 정적 사이트입니다.
- `main` 브랜치에 push하면 GitHub Actions가 빌드해서 GitHub Pages에 배포합니다.

### 글 쓰기

`src/content/blog/`에 마크다운 파일을 추가합니다.

```md
---
title: '글 제목'
description: '한 줄 설명'
pubDate: '2026-10-28'
---

본문
```

### 로컬에서 보기

```bash
npm install
npm run dev
```

http://localhost:4321 에서 확인할 수 있습니다.
